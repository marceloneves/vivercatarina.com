## CRITICAL

### C1 — Arquitetura hub/subdomínio não populada (cannibalização)
15 de 22 subdomínios com `sitemap-imoveis.xml` = **0 imóveis** (florianopolis inclusive). Os 110 imóveis de Floripa vivem no HUB, não no subdomínio. Hub e `florianopolis.` disputam a mesma intent "imóveis Florianópolis". `d-sense-centro-florianopolis-sc` existe (200) no hub, 404 no subdomínio.
- Não-zero imóveis: biguacu(13), blumenau(4), itapema(35), navegantes(5), portobelo(7), criciuma(30), chapeco(9).
- **Fix:** decidir modelo canônico — (a) hub agrega, subdomínio dono das fichas (canonical/link, sem duplicar) OU (b) hub redireciona. Popular feed por-cidade ou consertar filtro de cidade no build (`scripts/generate-sitemaps.mjs`).

### C2 — Zero Organization + WebSite schema no site inteiro
Nenhum `@type Organization`/`WebSite` em lugar nenhum (home, /about, fichas). Pior: `src/pages/quem-somos.astro:17-18` referencia `@id #organization` e `#website` que **não existem** → refs quebradas ao deployar.
- **Fix:** injetar Organization+WebSite JSON-LD uma vez no `PillerLayout.astro`. Antes de deployar quem-somos.

Snippet pronto (ajustar `logo` e preencher `sameAs` com perfis reais):
```json
{
  "@context": "https://schema.org",
  "@graph": [
    {
      "@type": "Organization",
      "@id": "https://vivercatarina.com/#organization",
      "name": "Viver Catarina",
      "url": "https://vivercatarina.com",
      "logo": "https://vivercatarina.com/assets/img/logo/logo.png",
      "email": "contato@vivercatarina.com",
      "telephone": "+5548988105199",
      "areaServed": "Santa Catarina, BR",
      "sameAs": []
    },
    {
      "@type": "WebSite",
      "@id": "https://vivercatarina.com/#website",
      "url": "https://vivercatarina.com",
      "name": "Viver Catarina",
      "inLanguage": "pt-BR",
      "publisher": { "@id": "https://vivercatarina.com/#organization" }
    }
  ]
}
```

### C3 — FAQ localizado duplicado e factualmente FALSO
Camboriú, Joinville, Tijucas, Itapema recebem resposta "Ilha ou Continente" byte-idêntica + lista de bairros de Floripa (Campeche, Cacupé, Trindade, Jurerê, Lagoa da Conceição, "pontes") só trocando o nome da cidade. Cidades sem ilha/pontes → erro factual + thin/spam.
- **Fix:** parametrizar gerador de FAQ por-cidade com geografia local real; remover linguagem "Ilha/Continente/pontes" fora de Floripa. (Gerador por-cidade não localizado neste repo — pode viver em pipeline/build separado.)

### C4 — HTTP sem redirect HTTPS + `www` duplicado
`http://vivercatarina.com` → 200 (sem 301, sem Location). `www.vivercatarina.com` serve conteúdo byte-idêntico (md5 igual), sem redirect, canonical aponta pro non-www mas é frágil. Duplicação de host, link equity dividido.
- **Fix:** 301 `http`→`https` e `www`→apex no edge. Não depender do canonical.

### C5 — Placeholder de tema WooCommerce/inglês vivo em produção
`/about` renderiza `"Pillar is a luxury to the resilience, adaptability... swimming pool blending indooroutdoor"`, widget "Carrinho / Item de exemplo × $940.00 USD", classes `wc-forward`, "Shopping cart/View cart/Checkout". Indexável (`d-none d-lg-block` visível no desktop).
- **Fix:** remover boilerplate do tema + mini-cart do layout compartilhado. `[deploy parcial]` — o /quem-somos novo substitui o miolo, mas o cart no shell segue.
